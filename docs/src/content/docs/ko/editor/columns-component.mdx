---
title: Columns 컴포넌트
description: 컬럼 표현식 편집용 FlyqlColumns 컴포넌트
---

`FlyqlColumns` 컴포넌트는 컬럼 표현식 전용 입력 UI를 제공합니다. 컬럼 선택, 필터링, transformer 적용을 지원합니다.

## 빠른 설정

```vue
<script setup>
import { ref } from 'vue'
import { FlyqlColumns, ColumnSchema } from 'flyql-vue'

const expr = ref('')
const columns = ColumnSchema.fromPlainObject({
    status: { type: 'number', suggest: true },
    level: { type: 'enum', suggest: true },
    service: { type: 'string', suggest: true },
    host: { type: 'string', suggest: true },
})

function onParsed(parsed) {
    console.log('Parsed columns:', parsed)
}
</script>

<template>
    <FlyqlColumns
        v-model="expr"
        :columns="columns"
        :capabilities="{ transformers: true }"
        placeholder="message, status|upper, host as h"
        @update:parsed="onParsed"
    />
</template>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `modelValue` | `String` | `''` | 표현식 텍스트 (`v-model`) |
| `columns` | `Object` | `{}` | 컬럼 [schema](/ko/editor/schema/) |
| `capabilities` | `Object` | `null` | parser capabilities (예: `{ transformers: true }`) |
| `onKeyDiscovery` | `Function` | `null` | 원격 키 탐색 callback |
| `placeholder` | `String` | `''` | placeholder 텍스트 |
| `autofocus` | `Boolean` | `false` | mount 시 자동 포커스 |
| `debug` | `Boolean` | `false` | 디버그 로깅 |
| `dark` | `Boolean` | `false` | 다크 테마 활성화 ([theming](/ko/editor/theming/) 참고) |
| `label` | `String` | `''` | 필드 안, 쿼리 왼쪽에 표시되는 텍스트 |
| `icon` | `String \| Object \| Function \| Boolean` | `null` | 라벨 앞에 표시되는 아이콘. 문자열은 텍스트로, 컴포넌트는 그대로 렌더링되며 `false`는 아이콘을 제거합니다 |
| `multiline` | `Boolean` | `true` | 여러 줄 입력을 허용합니다. `false`이면 줄바꿈이 공백으로 바뀌고 필드는 한 줄로 유지됩니다 |
| `hasClear` | `Boolean` | `false` | 끝쪽에 지우기 버튼을 표시합니다. 값이 있을 때만 나타납니다 |
| `clearButtonLabel` | `String` | `'Clear'` | 지우기 버튼의 접근성 이름 |
| `panelContainer` | `String \| Object` | `'body'` | 제안 패널을 어디에 포털할지: 선택자 또는 엘리먼트. 기본값 `body` |

## 라벨과 아이콘

`label`과 `icon`은 쿼리 텍스트 앞, 필드 왼쪽의 같은 자리를 공유합니다. 둘 중 어느 쪽을 클릭해도 입력에 포커스가 가며, 너무 긴 라벨은 입력을 좁히는 대신 필드 너비의 절반에서 말줄임표로 잘립니다. 텍스트 `label`은 입력의 접근성 이름이 되어 컴포넌트의 기본 `aria-label`을 대체합니다.

```vue
<template>
    <FlyqlColumns v-model="expr" :columns="columns" label="Filter" />
    <FlyqlColumns v-model="expr" :columns="columns" icon="🔎" />
    <FlyqlColumns v-model="expr" :columns="columns" :icon="MyIcon" />
    <FlyqlColumns v-model="expr" :columns="columns" :icon="false" label="Filter" />
</template>
```

더 풍부한 내용이 필요하면 `icon`과 `label` 슬롯이 props보다 우선합니다:

```vue
<template>
    <FlyqlColumns v-model="expr" :columns="columns">
        <template #icon><MyIcon /></template>
        <template #label><strong>Filter</strong></template>
    </FlyqlColumns>
</template>
```

## Events

| Event | Payload | 설명 |
|-------|---------|------|
| `update:modelValue` | `string` | 표현식 텍스트 변경 (`v-model`) |
| `update:parsed` | `ParsedColumn[]` | parse된 컬럼 배열 업데이트 |
| `submit` | — | 사용자가 Ctrl/Cmd+Enter를 누름 |
| `parse-error` | `string` | parse 오류 메시지 |
| `focus` | — | 컴포넌트가 포커스를 얻음 |
| `blur` | — | 컴포넌트가 포커스를 잃음 |

## 노출 메서드

| 메서드 | 반환값 | 설명 |
|--------|--------|------|
| `focus()` | — | 입력에 포커스 |
| `blur()` | — | 입력에서 포커스 제거 |
| `getQueryStatus()` | `{ valid: boolean, message: string }` | 표현식 검증 |
| `getParsedColumns()` | `ParsedColumn[]` | parse된 컬럼 배열 반환 |

## 컬럼 표현식 문법

컬럼 표현식은 쉼표로 구분되며, 선택적으로 transformer와 alias를 가질 수 있습니다.

```
message, status|upper, host as h, metadata.labels.env
```

| 부분 | 문법 | 예제 |
|------|------|------|
| 컬럼 | `name` | `message` |
| Transformer | `name\|transformer` | `status\|upper` |
| 인자 포함 Transformer | `name\|transformer(arg)` | `name\|truncate(50)` |
| Alias | `name as alias` | `host as h` |
| 중첩 | `parent.child` | `metadata.labels.env` |
| Transformer 체인 | `name\|t1\|t2` | `msg\|lower\|truncate(100)` |
