---
title: Componente Columns
description: Componente FlyqlColumns para edição de expressões de colunas
---

O componente `FlyqlColumns` fornece um campo dedicado para expressões de colunas — selecionando, filtrando e aplicando transformadores em colunas.

## Configuração Rápida

```vue
<script setup>
import { ref } from 'vue'
import { FlyqlColumns, ColumnSchema } from 'flyql-vue'

const expr = ref('')
const columns = ColumnSchema.fromPlainObject({
    status: { type: 'number', suggest: true },
    level: { type: 'enum', suggest: true },
    service: { type: 'string', suggest: true },
    host: { type: 'string', suggest: true },
})

function onParsed(parsed) {
    console.log('Parsed columns:', parsed)
}
</script>

<template>
    <FlyqlColumns
        v-model="expr"
        :columns="columns"
        :capabilities="{ transformers: true }"
        placeholder="message, status|upper, host as h"
        @update:parsed="onParsed"
    />
</template>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|------|------|---------|-------------|
| `modelValue` | `String` | `''` | Texto da expressão (v-model) |
| `columns` | `Object` | `{}` | [Schema](/pt-br/editor/schema/) de colunas |
| `capabilities` | `Object` | `null` | Capacidades do parser (ex.: `{ transformers: true }`) |
| `onKeyDiscovery` | `Function` | `null` | Callback de descoberta remota de chaves |
| `placeholder` | `String` | `''` | Texto do placeholder |
| `autofocus` | `Boolean` | `false` | Foco automático ao montar |
| `debug` | `Boolean` | `false` | Log de depuração |
| `dark` | `Boolean` | `false` | Ativar tema escuro ([veja temas](/pt-br/editor/theming/)) |
| `label` | `String` | `''` | Texto exibido dentro do campo, à esquerda da consulta |
| `icon` | `String \| Object \| Function \| Boolean` | `null` | Ícone exibido antes do rótulo: uma string é renderizada como texto, um componente como está, `false` o remove |

## Rótulo e ícone

`label` e `icon` dividem o espaço à esquerda do campo, antes do texto da consulta. Clicar em qualquer um deles foca a entrada, e um rótulo muito longo é truncado com reticências na metade da largura do campo em vez de espremer a entrada. Um `label` de texto também passa a ser o nome acessível da entrada, substituindo o `aria-label` padrão do componente.

```vue
<template>
    <FlyqlColumns v-model="expr" :columns="columns" label="Filter" />
    <FlyqlColumns v-model="expr" :columns="columns" icon="🔎" />
    <FlyqlColumns v-model="expr" :columns="columns" :icon="MyIcon" />
    <FlyqlColumns v-model="expr" :columns="columns" :icon="false" label="Filter" />
</template>
```

Os slots `icon` e `label` têm precedência sobre as props quando você precisa de conteúdo mais rico:

```vue
<template>
    <FlyqlColumns v-model="expr" :columns="columns">
        <template #icon><MyIcon /></template>
        <template #label><strong>Filter</strong></template>
    </FlyqlColumns>
</template>
```

## Eventos

| Evento | Payload | Descrição |
|-------|---------|-------------|
| `update:modelValue` | `string` | Texto da expressão alterado (v-model) |
| `update:parsed` | `ParsedColumn[]` | Array de colunas parseadas atualizado |
| `submit` | — | Usuário pressionou Shift+Enter |
| `parse-error` | `string` | Mensagem de erro de parse |
| `focus` | — | Componente recebeu foco |
| `blur` | — | Componente perdeu foco |

## Métodos Expostos

| Método | Retorno | Descrição |
|--------|---------|-------------|
| `focus()` | — | Focar o campo |
| `blur()` | — | Desfocar o campo |
| `getQueryStatus()` | `{ valid: boolean, message: string }` | Validar a expressão |
| `getParsedColumns()` | `ParsedColumn[]` | Obter array de colunas parseadas |

## Sintaxe de Expressões de Colunas

Expressões de colunas usam um formato separado por vírgulas com transformadores e aliases opcionais:

```
message, status|upper, host as h, metadata.labels.env
```

| Parte | Sintaxe | Exemplo |
|------|--------|---------|
| Coluna | `name` | `message` |
| Transformador | `name\|transformer` | `status\|upper` |
| Transformador com argumentos | `name\|transformer(arg)` | `name\|truncate(50)` |
| Alias | `name as alias` | `host as h` |
| Aninhado | `parent.child` | `metadata.labels.env` |
| Transformadores encadeados | `name\|t1\|t2` | `msg\|lower\|truncate(100)` |
